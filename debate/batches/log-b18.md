
### Round 274. Winner: Designer
- Topic: Label leakage through agent-side context: the state's tool list and the preceding fragment predict the event, so Needle learns "what this state usually hears", not what the caller said
- Attack: The big model generates data state by state. In READ_BACK_CONFIRM, 90% of generated caller turns are affirm, because the generator is prompted "customer responds to the confirmation question". Needle's LOCAL input includes the state's tool list and the agent's last fragment. Training loss drops fastest by keying on that context. Live, a caller answers the confirmation with an off-pattern "hold on, my wife has to see the paperwork first". Needle outputs affirm with a wide margin. No near-tie, no clarify. Per-state generation makes the context a near-perfect label proxy. That is classic target leakage. Held-out synthetic tests share the same leak, so they score high. The margin gate fires only on near-ties, but a leaked prior produces confident errors, not ties. Grounding checks slots, not events, so an affirm with no slots passes it.
- Defense: The leaked prior cannot certify anything: synthetic data "never certifies" (R2), and whole-trace bounds come only from Needle-driven real calls with 100% audit in the canary cohort (R124). There, the real READ_BACK affirm rate is far below 90%, so confident wrong affirms show up as Tier A harm. It also can't reach a commit. "Hold on, my wife has to see the paperwork" holds no lexical affirm. The commit gate is "lexical over final ASR tokens (independent of Needle output)" (R87). It excludes conditional answers (R86). It now requires the caller to say "send the contract" (R144). So the turn becomes a re-ask, not a sale. The R127 artifact audit already probes for shortcut labels per source.
- Verdict: The harm in the scenario can't happen with the existing design. The commit gate is lexical over final ASR tokens and ignores Needle's output (R87). Conditional answers are excluded (R86), and the caller must say "send the contract" (R144), so a leaked confident affirm on "my wife has to see the paperwork first" only causes a re-ask. Synthetic sets never certify (R2), and the Needle-driven canary with 100% audit (R124) measures the real affirm rate, so a leaked prior shows up as real errors instead of passing on a synthetic score.

### Round 275. Winner: Designer
- Topic: The teacher's covert dialect prejudice becomes the label set: the big model, as stand-in classifier and synthetic labeler, scores dialect speakers as hostile, unclear or out of scope
- Attack: In the build phase the big model labels real calls, and Needle is distilled from those labels. A Black homeowner says in AAE "I been told y'all about that roof." The teacher labels it dispute_prior_statement or unclear, where a Standard English paraphrase gets acknowledge. Dialect transforms it generates carry the same skew in their labels. Needle copies the pattern: more clarifies, more fallbacks and hostile-exit routing for AAE speakers. The human audit samples only some agreements. Hofmann et al., Nature 633 (2024), showed LLMs hold covert, dialect-triggered prejudice against AAE even when overt bias is trained away. Distillation inherits the teacher's labels. Per-group bounds measure harm only on audited calls, while the training labels are big-model labels. (news.uchicago.edu/story/ai-biased-against-speakers-african-american-english-study-finds)
- Defense: Dialect transforms are Multi-VALUE-style rule transforms of labeled source items (R93), so the label is inherited, not re-judged by the teacher. The gate never trusts teacher labels. Tier A bounds come from humans listening to audio (R26). Strata are defined by observable features and annotated by two trained auditors (R131), with per-dialect bounds as release blockers (R93) and a label-free worst-cluster check. A skewed teacher therefore blocks release; it can't certify. The cited outcome is also mild: dispute_prior_statement only re-reads a table value (R91), and clarify is not a hostile exit.
- Verdict: Teacher labels never gate a release. Gold labels come from humans listening to audio, with per-group clarification and error bounds (R26). Per-dialect bounds block release (R93), and R131 adds feature-based strata, two auditors and a label-free worst-cluster check, so extra clarifies or misroutes for AAE speakers block release instead of shipping. Dialect transforms are rule-based and keep the source label (R93), and the cited outcomes (dispute re-read, clarify) are not hostile exits.

### Round 276. Winner: Breaker
- Topic: The teacher's own safety alignment sanitizes the safety-critical classes: it refuses or softens realistic suicidal, abusive, threatening and fraud-seeking caller turns
- Attack: The pipeline asks the big model for 5,000 sensitive_event and unlawful_request examples with oblique, realistic wording. It refuses some prompts, and the rest come back textbook-explicit: "I am feeling suicidal." Threats, slurs and loan-fraud asks come out polite and stereotyped. Needle learns that only explicit phrasing is sensitive. A real caller says "doesn't matter, I won't be around for the install anyway." Needle labels it small_talk and the pitch continues. The aligned teacher's refusal and harmlessness filters bias exactly the rare classes that are Tier A. The red team uses the same aligned models, so the sanitized wording also sets the test distribution. Synthetic coverage of these classes looks complete while the oblique real-world tail stays empty.
- Defense: Safety does not rest on synthetic coverage. Sensitive events have "deterministic lexicon pre-emption" (R19) and explicit hardship rows (R150). The red team is "model-diverse ... plus human-written seed attacks" (R97). Certification counts only real audited calls (R2), so a missed oblique ideation turn is counted Tier A harm and blocks the state. Label-free drift monitors on 100% of traffic cover out_of_scope growth and hang-up-after-turn (R132). Euphemisms are a named open item, not a hidden one.
- Verdict: The existing design names euphemisms as an open item and has no rule for training the oblique tail of sensitive_event. Nothing checks whether the aligned generator refuses or sanitizes these classes. R2 lists sensitive misses under neither tier (Tier A is opt-out, confirm_order, consent and critical slots), so they can fall under model-agreement labels. A sanitized teacher and a student that both call "won't be around for the install" small_talk agree, and that turn is seen only through random-agreement audit. The defense's real closure (sanitization audit, non-refusing writers, passive-ideation lexicon rows, recall-biased threshold) is all new.
- Fix: Make missed sensitive_event and unlawful_request turns Tier A, with human-audited gold only. Run a sanitization audit per class each release that compares generator refusal rate and explicitness against a human-written oblique set, and block release if it fails. Source oblique examples from consented, crisis-informed human writers. Add passive-ideation and indirect-threat lexicon rows to the deterministic pre-emption, with the scripted sensitive exit, and give sensitive_event a recall-biased per-event threshold in the R189 multi-label GLOBAL pass.

### Round 277. Winner: Designer
- Topic: Simulated ASR noise does not match the pinned ASR's real confusion profile, so Needle is robust to errors the real ASR never makes
- Attack: The big model writes "ASR errors" as plausible-looking typos, dropped words and homophones. The pinned ASR actually fails differently: it inserts fillers on noise, merges words across a narrowband codec, applies ITN quirks ("for" becomes "4") and has accent-specific substitutions. Needle trains on millions of LLM-imagined corruptions and scores well on synthetic noise sets. Live, the real ASR's patterns fall outside training, and error rates on noisy calls are several times the synthetic estimate. Noise augmentation helps only when it matches the deployed channel's error distribution. An LLM has never seen this ASR's confusion matrix. The certified ASR version is pinned, but the data generator is not conditioned on it. Every robustness number drawn from synthetic noise therefore overstates real performance.
- Defense: No robustness number from synthetic noise certifies anything (R2). Certification runs "on live ASR text" from the pinned ASR (R26, R68), stratified by channel class (R137), so the real confusion profile is what gets measured. The canonicalizer feeds Needle canonical text in training and certification alike (R68), which removes ITN quirks like "4" for "for" before Needle sees them. The design already applies this principle elsewhere. The big model may not write prosody tokens; they come only from the pinned detector run on audio (R128).
- Verdict: Synthetic noise numbers never certify (R2). Certification runs on live text from the pinned ASR (R26, R68), stratified by channel class (R137), so the real confusion profile is what gets measured, and the canonicalizer is applied the same way in training and certification. A mismatch costs capability (more states stay on fallback), not unmeasured harm.

### Round 278. Winner: Designer
- Topic: Event-schema growth leaves historical labels wrong: when an out_of_scope cluster becomes a new event, all older data still teaches the old label
- Attack: Release 14 adds the event leave_taking, split from out_of_scope and acknowledge. 400k historical examples that say "okay thanks bye" stay labeled acknowledge, because real data is never replaced. The new event has 3k fresh examples. Training sees about 130 conflicting acknowledge labels for each leave_taking label. Needle learns acknowledge for most goodbyes, and the new event certifies only on its own small fresh test set. Every schema change creates relabeling debt across the whole union of data, but the design says to add events and to keep real data, with no migration step. Label noise is systematic, concentrated on the very boundary the new event exists to fix. The per-source caps don't help: the conflict lies inside each source.
- Defense: A conflicted boundary can't certify. Bounds are per call, on whole audited real traces (R66), not on the new event's own test set. The goodbye boundary is a certified confusion pair, like small_talk vs unintelligible (R63). An acknowledge given to a real "okay thanks bye" counts as an error against human audio labels. Calibration re-fits event priors on a real audited split (R133). New events are added only through a threshold process (R36). "Real data never replaced" (R33) forbids swapping real data for synthetic. It does not forbid relabeling.
- Verdict: The attack's key claim, that the new event "certifies only on its own small fresh test set", is false. Bounds are per call over whole audited real traces (R66), on human audio labels (R26), and goodbyes happen on almost every call, so a confused boundary shows up as real errors and blocks the state. Stale labels make it harder to learn the new event, but they can't produce a false certificate. R33 forbids replacing real data, not relabeling it.

### Round 279. Winner: Designer
- Topic: Training examples are not keyed to the graph version they were labeled against, so tool renames, merges and description edits mix incompatible supervision
- Attack: In graph v7 the tool book_consult(time) is split into book_in_home(time) and book_video(time), and the description of request_human is reworded. The union of data still holds 200k v1–v6 examples whose targets are book_consult, or that were generated against the old descriptions. Some are filtered out, and the rest are rewritten by script. Needle learns that "come out to my house" is sometimes book_video. The tool-list hash certifies the new list, not the provenance of the data that trained it. The certificate pins the deployed tool list, while training data carries no graph-version key or migration audit. Needle conditions on tool names and descriptions, so stale examples are inconsistent supervision. Old graph versions can't be replayed through the new schema, so nothing checks that each example's label is still valid.
- Defense: The tool list is derived from handlers (R52), and the certificate is keyed by tool-list hash (R34, R53). Certification uses only Needle-driven real calls under the new list (R124). So "come out to my house" mapped to book_video is an audited booking error and blocks the state. Generator-prompt lineage already exists (R129), and cross-version state migration is allowed only through a model-checked map (R67). The gap is training-item provenance, which I close below.
- Verdict: Tool lists are derived from handlers (R52), and the certificate is keyed on the tool-list hash (R34, R53). It is earned only on Needle-driven real calls under the new list (R124), so mapping "come out to my house" to book_video is an audited error that blocks the state. Inconsistent old supervision degrades learning, but it can't be certified past the gate.

### Round 280. Winner: Designer
- Topic: The teacher model is a moving, retirable API, so the synthetic training set cannot be reproduced and a certified build can't be rebuilt
- Attack: Release 9 was certified. Its data came from teacher version X through a vendor endpoint. The vendor silently updates X's behavior, then retires it. A regulator or plaintiff asks for the build to be reproduced, or a hotfix needs the same data regenerated with one more paraphrase family. Regenerating with the successor model shifts label rates and phrasing, so "the same pipeline" yields a different Needle that fails old regression slices. Bit-identical replay covers inference, not training. Chen, Zaharia and Zou (2023) measured large behavior shifts in the "same" GPT-4 and GPT-3.5 model names over months. The bundle hashes weights, not teacher version, prompts and sampling seeds. Without those, the evidence chain from data to certificate can't be rebuilt. (arxiv.org/abs/2307.09009)
- Defense: The certificate never rests on reproducing training. It rests on the hashed weights' behavior on real, human-audited calls (R2, R53). Those weights are kept in immutable retained bundles (R67) with bit-identical replay. A regulator can audit the certified artifact and its evidence without rerunning the teacher. A hotfix never regenerates the old data. It adds data to the union, since real data is never replaced (R33), and recertifies on fresh samples (R126). Regression items are retained (R129) so differences show up.
- Verdict: The certificate rests on the hashed weights' behaviour on human-audited real calls (R2, R53), not on re-running training. Those weights sit in immutable retained bundles with bit-identical replay (R67). Training each release on the union of all data (R33, R3) means the generated corpus is kept and added to, not regenerated, so a retired teacher can't break a hotfix.

### Round 281. Winner: Breaker
- Topic: Audit labelers anchored on the model's proposed label (automation bias) contaminate the human ground truth that gates certification
- Attack: To hit audit throughput, the labeling UI pre-fills each turn with Needle's or the big model's event and the labeler confirms or corrects it. On a fast "yeah, no, go ahead and send it, I'll look," the pre-fill says affirm. A tired labeler listening at 1.5x accepts it. Across 100k audited turns, borderline cases follow the suggestion. The measured harm rate falls, and states certify. Pre-annotation measurably shifts human judgments toward the suggestion. The ground truth then correlates with the model it is grading, biasing harm estimates downward exactly at the margin. The design says "humans listening to audio" but never requires blind, unprimed labeling or measures agreement against blind double-labels. (arxiv.org/abs/2509.08514)
- Defense: The gate requires humans "listening to audio" (R26). Strata use two trained auditors with measured inter-rater agreement and confusion correction (R131). Selection of "all disagreements + random agreements" (R2) uses model labels to choose clips; nothing requires showing those labels to the labeler. The commit gate is lexical (R87) and needs "send the contract" (R144). So "yeah, no, go ahead and send it" can't commit through a pre-filled affirm. Still, blind labeling must be explicit.
- Verdict: The certification ground truth is the whole safety argument, yet the design nowhere requires event labelers to be blind to the model's label. R26 says only "humans listening to audio". R131's two auditors and agreement measures cover dialect-strata labels, not event labels, and R221's blind rule covers only complaint labels. The lexical commit gate saves the one example given, but pre-filled labels would bias stop, consent and critical-slot labels downward for every Tier A state, and the defense concedes that blind labeling "must be explicit".
- Fix: Label Tier A gold blind: the UI shows no Needle or teacher label, playback is fixed at 1x, and a random share is double-labeled blind with adjudication. Seed known-answer items and remove labelers who fall below an accuracy floor. Allow pre-fill only for Tier B, and correct those estimates by the bias measured against blind double labels.

### Round 282. Winner: Designer
- Topic: Adaptive overfitting to a reused certification and golden set: release-by-release tuning of thresholds, caps and data mixes against the same audited pools
- Attack: Each release, engineers see which states missed the bound on the audited pool and the golden canary. They tweak the clarify margin, upsample the failing intent and adjust per-source caps, then re-check against the same pools. After 20 releases every state passes. Each tweak was small, but together they fit the particular calls in those pools. On a fresh month of traffic, three Tier A states exceed the bound. Reusing a holdout adaptively makes it a training set. Dwork et al. (Science 2015) show that repeated, data-dependent queries invalidate holdout guarantees. This is not contamination by ingestion, and not simultaneous multiple comparisons: it is serial, human-in-the-loop selection. The design has no fresh-only evaluation rule, no limit on queries to the holdout and no fresh-holdout budget.
- Defense: This is already closed. R126: "Tuning and promotion use an exploration sample. Certification uses a fresh confirmatory sample collected after the promotion decision, and it is used once." A failed state keeps its failing evidence, and retries run as a pre-registered sequential test under a family-wise alpha. Calibration has its own split (R133). The golden canary is a bit-diff regression test (R68), not a bound. After release, continuous audited sampling of fresh traffic and label-free drift monitors (R33, R132) catch any fit to old pools.
- Verdict: R126 already closes this. Tuning and promotion use an exploration sample, and certification uses a fresh confirmatory sample collected after the promotion decision and used once, with family-wise alpha and pre-registered sequential retries. Calibration has its own split (R133), the golden canary is a bit-diff regression test rather than a bound (R68), and continuous audits on fresh traffic plus label-free drift monitors (R33, R132) cover what happens after release.

### Round 283. Winner: Designer
- Topic: Retraining cadence vs certification evidence: an urgent fix needs new weights, and new weights reset the real-call evidence every state needs
- Attack: A new stop euphemism spreads ("unsubscribe me" after a viral post). Fixing it needs a Needle retrain on the union of data. New weights get a new hash, so every state's certificate is void and needs fresh human-audited real calls. At 1e-5 with rule-of-three, that is about 300k audited calls per Tier A state. Options: run uncertified weights, run the whole fleet on deterministic fallback for months, or leave the missed stops live. The cadence is set by audit throughput, not by risk. Global shared weights mean no fix is local: a one-intent patch re-opens every state. The bound can only be measured on real calls by that release, so evidence can't carry over. No release can fix a known harm faster than months of new audits allow, and that pushes operators toward exemptions.
- Defense: A stop fix needs no retrain. Stop is the "union of deterministic lexicon ... and Needle GLOBAL" (final plan). "Unsubscribe me" is added as a lexicon row (as in R145 and R93), and the post-call DNC sweep catches anything missed before a redial (R66). Union can only add stops, so false-continue can only fall. GLOBAL is "versioned separately" (R34). When weights must change, equivalence-based re-keying keeps every state whose outputs are bitwise identical on its gold and canary corpus (R135). Only diverging states recertify, on fallback.
- Verdict: The scenario's fix needs no retrain. Stop is the union of the deterministic lexicon and GLOBAL (R66), so adding "unsubscribe me" as a lexicon row can only add stops, and the post-call sweep catches misses before any redial. Sensitive (R19), unlawful (R86) and hardship (R150) events have the same lexicon lanes, and a degraded LOCAL state falls back to deterministic fallback (R132), which is safe rather than uncertified. Slow cadence costs coverage, not safety.
