## A1
DEFENSE: The design never assumes "more big-model data converges". Release is gated only on real-call, human-audited bounds (R2), so a state whose accuracy plateaus simply stays on deterministic fallback; it does not ship. Needle's job is also cut down to what 26M can do: one numeric slot per QUALIFY question (R186), exact-entity grounding (R185), role-binding and negation cross-check (R186), and every qualification-critical slot is read back and confirmed (R2 critical-slot read-back), so "moving" mapped to move_horizon gets corrected aloud. The ownership-change question is neutral and "any yes -> NOT_SUITABLE" (R208). Teacher labels are barred wherever teacher-vs-human disagreement is high (R275). Discourse reasoning lives in code (condition_stated, R289; defers_decision, R15), not in Needle.
EXISTING ELEMENTS: R2 real-call gate + fallback + critical-slot read-back; R185 grounding; R186 role-binding cross-check; R208 ownership-change question; R275 teacher labels barred per stratum; R289 condition_stated; R15 defers_decision
NEW HARDENING: NEW (1) Soft targets: the training loss adds the teacher's temperature-scaled top-k event distribution as an auxiliary KD term, alongside human/hard labels. (2) An offline mid-size teacher-assistant model, distilled from the big model, produces those soft targets (offline only, never in the call path). (3) A per-state learning-curve check: if audited real accuracy hasn't improved over the last two data doublings, more data is frozen for that state. The state is split into narrower questions or stays on fallback. (4) Any hedged or conditional answer to a suitability question ("might", "depends") resolves to the conservative value (NOT_SUITABLE or human review), never to a numeric slot.

## A2
DEFENSE: Retirement removes the big model from the call path only. R36 says "after retirement big model is offline-only", so it still exists as an offline second opinion. Label-free monitors run on 100% of traffic: lexicon-vs-Needle disagreement, near-tie and clarify rate, out_of_scope cluster growth, hang-up-after-turn, each with CUSUM and an automatic audit surge (R132). The deterministic stop/cancel lexicon is a permanent second classifier: the post-call sweep re-runs lexicon + GLOBAL on every transcript (R66), extended to cancel intents (R189). Rescinds also arrive out of band through the revocation intake bus (R115), complaint feeds (R271), and capture-recapture estimation across human, sweep and complaint channels (R257). R97 adds extra audits where models agree confidently.
EXISTING ELEMENTS: R36 offline-only big model; R132 label-free drift monitors + lexicon-vs-Needle disagreement + audit surge; R66 post-call sweep; R189 cancel lexicon in sweep; R115 revocation intake bus; R271 complaint intake; R257 capture-recapture; R97 high-confidence agreement audits; R33 continuous audited sampling
NEW HARDENING: NEW (1) Post-retirement offline relabeling. Every retired state's transcripts are relabeled nightly, after surrogate scrubbing (R7), by the offline big model and by a second model from a different family. Disagreements fill the audit queue, the same way pre-retirement disagreements did. DAgger continues offline: the learner's recorded states get expert labels after the call, which DAgger allows. (2) Outcome-triggered audit: any rescind, cancel, complaint or void within the window pulls that whole call into a 100% audit.

## A3
DEFENSE: Cross-turn context is not supposed to live in Needle. It lives in the slot store and the state. Commit needs a lexical affirm bound to the instance-scoped read-back question id (R87, R337), given as an action-production phrase (R144), so "yeah, that's fine" after a monologue cannot commit. "Only if my son's on" is captured when spoken, as condition_stated (R289) or defers_decision -> SUPPORT_PERSON (R243), and code blocks the close. The big model is "only a stand-in classifier on the same schema/templates" (R54). Training items store only the utterance + target event, with state context re-rendered from the graph (R279). The context-only probe (R274) checks the related leakage. Tier A gold is labeled by humans, blind (R281).
EXISTING ELEMENTS: R54 same-schema stand-in; R279 utterance + re-rendered context; R274 leakage probe; R87 lexical commit gate; R337 instance-scoped qid; R144 action-production prompt; R289 condition_stated; R243 SUPPORT_PERSON; R281 blind labeling
NEW HARDENING: NEW (1) Observation-matched labeling. Teacher and human labelers label each turn in Needle's exact view (state, last agent fragment, canonical turn). A separate whole-call field records the context-aware reading. Any mismatch marks the item context-dependent: the needed context becomes a deterministic slot fed into the state (a new guard or state input), or the item is masked. (2) Conflict detector: identical (state, canonical text) pairs with conflicting labels are collapsed to ambiguous_polarity/clarify (R77) and reported per release.

## A4
DEFENSE: The design does not rely on RLHF paraphrase for real-caller coverage. Dialect variation comes from rule-based Multi-VALUE transforms (R93), which keep the source label (R275), with an AAE/Spanglish allowlist that is exempt from quarantine (R130). Noise comes from TTS + pinned ASR and from an empirical confusion model fitted on real calls; LLM-written ASR errors are banned (R277). Real on-policy build-phase calls are the core data and are never replaced (R20, R33). Human-written seeds supplement them (R97). The surface-only artifact probe (R127) catches style shortcuts. Coverage does not certify: synthetic data never counts toward the gate (R2), and per-dialect and worst-acoustic-cluster real bounds are release blockers (R26, R131, R255). The Tier 1 stop lexicon covers short forms deterministically (R24, R93).
EXISTING ELEMENTS: R93 Multi-VALUE transforms + dialect stop patterns; R275 label-preserving transforms; R130 dialect allowlist; R277 TTS/empirical noise; R20/R33 real on-policy data; R97 human-written seeds; R127 artifact audit; R2 synthetic never certifies; R131/R255 worst-group bounds; R24 Tier 1 lexicon
NEW HARDENING: NEW (1) Coverage is measured against real build-phase turns, not as a count per label. Each real turn's nearest-neighbour distance to the training set, and its length/token-shape distribution, is a release check. Uncovered real regions (short fragments, non-standard forms) are reported. (2) Generation for those regions is seeded with real-turn fragments as templates and uses a base (non-RLHF) model at higher temperature. (3) A short-fragment stratum (under 4 tokens) is Tier A for stop/decline.

## A5
DEFENSE: Spoken entities never choose tariff rows. The calculator is keyed by (delivery utility, generation provider, schedule). Those come only from the utility authorization API or the bill extractor (R156, R227, R212 tariff_class), so "TXU" vs "Oncor" can't select a wrong tariff, and an unknown provider means no figure (R227). The bill-reconciliation gate must reproduce actual billed amounts or no figure is given (R228). Roof suitability comes from roof/shade data lookup and LIDAR geometry (R79, R230), with ROOF_FIRST inspection before any quote (R71). Grounding requires exact equality with one complete extracted entity (R185). Utility is a qualification-critical slot that gets read back (R2).
EXISTING ELEMENTS: R156 usage authorization; R227 generation_provider writers; R212 tariff_class; R228 bill-reconciliation gate; R79/R230 roof data; R71 ROOF_FIRST; R185 grounding; R2 critical-slot read-back; R72 spoken values only fill routing bands
NEW HARDENING: NEW (1) Entity canonicalization moves out of Needle. Needle emits only the span. A deterministic resolver maps it through a versioned alias table (EIA-861 utilities, retail providers and CCAs, filtered to the candidate set for the geocoded service territory; roof-material list). 0 or >1 matches -> clarify; unknown -> no figure. (2) A spoken utility that disagrees with the API value -> API wins, and the turn is logged as a resolver test case.

## A6
DEFENSE: The slot values that drive pricing and identity are not learned from scrubbed spans. Numbers go through a deterministic normalizer and "Needle never aggregates numbers" (R43). Spoken amounts only fill coarse routing bands (R72). Savings come only from verified_usage or a bill extractor (R61, R156). The attacker's own example, "two-eighty-seven, two-ninety in summer", is exactly R185: "a turn with two candidate values for one slot (summer/winter) goes to clarify(slot) naming the period." Identity uses a deterministic challenge-response match (R73) with a token-set name matcher for hyphenated and compound surnames (R146). Certification uses real gold utterances (R7, R2), so this skew is measured.
EXISTING ELEMENTS: R43 number normalizer; R72 coarse bands; R61 grounding + verified usage; R156; R185 two-value clarify; R73 challenge-response; R146 token-set name matcher; R7 real gold sets; R2 real-only certification
NEW HARDENING: NEW (1) Shape-preserving surrogates. A scrubbed span is replaced by a value sampled from the empirical distribution of real extractor outputs that keeps the verbalization pattern ("two-eighty-seven" -> "three-forty-one"; ranges stay ranges; names drawn from census surname lists including hyphenated and multi-token forms). (2) A release check compares slot-value shape histograms between real gold and training data; a gap blocks release.

## A7
DEFENSE: The thresholds are not fitted on synthetic data. R133: "each release runs a calibration step on a real, audited calibration split", with temperature scaling plus label-shift correction to live priors. Margin, OOD and clarify thresholds are re-set to target false-stop and false-commit rates. The OOD score is pre-mask off-schema mass (R125). Commit does not trust Needle confidence at all: it is lexical (R87), needs voicing evidence (R104), an action-production phrase (R144) and a safety-mass veto (R190). Critical slots are read back (R2). Under shift, clarify and near-tie rate, event mix and off-schema mass are CUSUM-monitored on 100% of traffic, with audit surge and Tier A fallback (R132).
EXISTING ELEMENTS: R133 real calibration split + label-shift correction; R125 OOD mass; R87 lexical commit; R104 voicing gate; R144; R190 safety-mass veto; R2 read-back + real-only certification; R132 drift monitors; R126 confirmatory sample
NEW HARDENING: NEW (1) Per-stratum selective-risk check: on the real calibration split, the risk at the chosen threshold is computed per dialect stratum and worst acoustic cluster (R131). Any group above target blocks release or gets its own threshold. (2) Conformal risk control replaces plain temperature scaling for Tier A thresholds. (3) A divergence alarm: clarify rate falling while out_of_scope growth or hang-up-after-turn rises -> audit surge.

## A8
DEFENSE: The certification evidence is not gathered at the teacher's latency. R124: "Whole-trace Tier A/B bounds and rule-of-three counts come only from calls where Needle actually drove the transitions", through a Needle-driven canary cohort with 100% human audit before any wider ramp. The confirmatory sample is collected fresh after promotion (R126). Silence and endpointing timers are fit from real ASR timestamps and A/B tested (R65, R25). Long turns have their own segmenter and Tier A stratum (R44). "Hello?" maps to repair_request (R48). Label-shift correction re-fits to the event priors of the live deployment (R133). Event-mix and hang-up drift on the new rhythm triggers audit surges (R132).
EXISTING ELEMENTS: R124 Needle-driven canary with 100% audit; R126 fresh confirmatory sample; R65/R25 timers fit on real calls; R44 long-turn stratum; R48 repair_request; R133 live priors; R132 drift monitors; R100 p95 latency measured
NEW HARDENING: NEW (1) Every build-phase turn is tagged with the preceding agent response gap. Turns after a gap over 700 ms form a "latency-affected" stratum, down-weighted in training and excluded from calibration. (2) Turn-length, overlap and barge-in distributions are compared between the build phase and the Needle-driven canary per state. A shift blocks widening the ramp until timers and thresholds are refit on canary data.

## A9
DEFENSE: Label noise on hedges cannot produce a commit. "Sure, I guess we could look at it" fails the lexical commit gate (R87), the short-direct-answer check (R81) and the action-production prompt "please say 'send the contract'" (R144), whatever Needle learned. Hedges have their own classes: ambiguous_polarity -> clarify (R77) and indirect_decline with a fixed closed question (R145). Mislabeling a soft deferral as stop is conservative: a false stop is "a business cost and not a harm" (R254). Tier A gold is human-labeled blind (R2, R281). Counterfactual minimal pairs and the artifact probe target this boundary (R127). Generation is prompted by target event with a balanced mix (R274), and teacher labels are checked against humans (R275).
EXISTING ELEMENTS: R87 lexical commit; R81 short direct answer; R144 action-production prompt; R77 ambiguous_polarity; R145 indirect_decline; R254 false stop = cost; R2/R281 human blind gold; R127 minimal pairs; R274; R275
NEW HARDENING: NEW (1) Read-not-requested labels. Every generated boundary item is relabeled blind by a model from a different family, without the requested label. Disagreements go to human relabel or are dropped. (2) A per-class label-noise rate is measured on a blind human sample of synthetic boundary items each release. A rate above threshold blocks release for that class. (3) "Hedge" is an explicit generator target that maps to ambiguous_polarity, never to affirm or stop.

## A10
DEFENSE: A seed draw can't slip into production on synthetic scores. The certificate is keyed on the weights hash (R53), so each new seed is a new artifact. It goes through shadow, then a Needle-driven canary with 100% audit (R124), and a fresh confirmatory sample used once (R126). Training is seeded and deterministic (R280), and frozen real gold is replayed every build (R3). The safety tails don't depend on the seed: stop is the union with a deterministic lexicon (R66), and "take me off" is literally in Tier 1 (R24). Commit is lexical (R87). Dialect matched-pair tests are release blockers (R275, R93). Monotone patches inherit certificates (R254), and GLOBAL/LOCAL weights are separate (R283).
EXISTING ELEMENTS: R53 weights-hash certificate; R124 staged ramp; R126 confirmatory sample; R280 seeded training; R3 gold replay; R66 stop union; R24 Tier 1 lexicon; R87 lexical commit; R275/R93 matched pairs; R254 monotone patch; R283 split GLOBAL/LOCAL
NEW HARDENING: NEW (1) Train K seeds and select by the worst case over stress suites (dialect matched pairs, minimal pairs, real gold replay), not by the mean. (2) Seed churn on real gold is a release metric. (3) GLOBAL runs as an OR-ensemble of K seed weights (any fires -> event, a monotone superset per R254). In commit-capable LOCAL states, any seed disagreement -> clarify. (4) Warm-start plus a distillation term from the previous certified weights, to limit churn between releases.
