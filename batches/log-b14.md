- Topic: Interpreters speak in the first person, so an interpreted "yes, I agree" passes the COMMIT gate while the owner never heard the read-back
- Attack: Mrs. Tran (Vietnamese, record owner) puts her bilingual grandson on speaker. He renders consecutively in the first person, as interpreters are trained to: "I understand, I'm 82, I agree." First-person interpreting removes both markers, so the agent's evidence that the owner heard READ_BACK is a hearsay rendering from an unvetted, possibly interested, possibly minor interpreter. Nothing tells the agent that interpretation is happening.

R148 means no close on any second voice during QUALIFY/READ_BACK/COMMIT, so Mrs. Tran's Vietnamese on speaker blocks the close. R144 requires an action phrase plus a teach-back. For an 82-year-old, R148's human owner-only call before install would expose that the owner never understood the deal. The residual case is a grandson who answers IDENTITY himself and interprets off-mic. ### Round 235. Winner: Designer
- Topic: Cross-lingual false friends in one-word polar answers (Polish/Czech "no" = yeah, Greek "ne" = yes, Spanish "ya" = enough)
- Attack: Polish-born owner, fluent English, answers the commit question by reflex: "No, no, dobrze" = "yeah, yeah, fine". English ASR emits "No, no, the best." The stop lexicon fires or the gate re-asks, and he leaves. Reverse case: a Greek speaker says "Ochi... ne, ne" ("no... well, yes, yes"); or a Spanish speaker's annoyed "Ya, ya, ya" ("enough!") is transcribed "Yeah yeah yeah" and passes as a short lexical affirm on a closed re-ask. The COMMIT gate and stop lexicon are English lexical tests. Code-switched discourse particles are the commonest switch and are exactly one short token, the shape the gate trusts. English ASR maps them onto English homophones with high confidence, so the confidence pre-gate and grounding gate see clean text.
- Defense: The commit no longer turns on a polar word. R144 made the commit "an action-production prompt ('To have the contract sent, please say send the contract'), not a yes/no." Neither "Ya ya ya" nor "Ne, ne" produces that phrase, so a misheard particle can't commit anything. A Polish "No, no" that hits the stop lexicon goes through R24's Tier 2 path for a bare ambiguous "no", which asks "Should I keep going, or would you rather I let you go?" That is a false stop, which costs a sale but never harms the caller. R77 has the audio-informed ambiguous_polarity class and certifies "discourse-marker idioms per dialect". R130 keeps a "dialect/code-switch allowlist", and R131 uses L1-accent strata with release-blocking per-group bounds. R16's mixed counter flags code-switching.
- Verdict: R144 turned the commit into an action-production prompt ("say 'send the contract'"), so a misheard "ya ya ya" or "ne, ne" can't commit anything. R24 treats a bare "no" as Tier 2 at most: one check question, then a polite end. A false stop costs a sale but doesn't harm the caller. R77's per-dialect discourse-marker certification and R16's mixed counter already exist.

### Round 236. Winner: Breaker

### Round 239. Winner: Designer

- Attack: At COMMIT an ambiguous answer triggers the certified closed re-ask: "Just so I'm clear: is that a no, or a yes?" The design's fallback for ambiguity is the very format that converts ambiguity into the last-named option, and per-branch certification will measure that as a clean commit.

Ambiguity also adds to R15's vulnerability counter ("unclear()/contradictions -> NO_SALE_SAFE_EXIT"). A commit still has to survive R15's teach-back, where the caller produces payment and term unprompted, which echolalia can't do. R144 delays the teach-back after an intervening topic. R152's overcommitment signals and R148's owner-only call follow. Per-branch certification counts unsuitable closes as Tier A harm (R71) through the human-audited "consent understood" label (R144), so this would show up as harm, not a clean commit.
- Verdict: Under R144 the binary re-ask no longer decides the commit. A recency-biased "yes" is not the action phrase, and the close still needs R15's teach-back, where a number has to be produced, which echolalia can't supply. R15's counter also takes unclear answers and contradictions toward NO_SALE_SAFE_EXIT, and R144's "consent understood" audit label would count such closes as harm.
