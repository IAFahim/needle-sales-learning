## A1
DEFENSE: The leaked prior cannot certify anything: synthetic data "never certifies" (R2), and whole-trace bounds come only from Needle-driven real calls with 100% audit in the canary cohort (R124). There, the real READ_BACK affirm rate is far below 90%, so confident wrong affirms show up as Tier A harm. It also can't reach a commit. "Hold on, my wife has to see the paperwork" holds no lexical affirm. The commit gate is "lexical over final ASR tokens (independent of Needle output)" (R87). It excludes conditional answers (R86). It now requires the caller to say "send the contract" (R144). So the turn becomes a re-ask, not a sale. The R127 artifact audit already probes for shortcut labels per source.
EXISTING ELEMENTS: R2 real-calls-only gate; R124 Needle-driven canary with 100% audit; R87 lexical commit gate; R86/R9 conditional affirms excluded; R144 action-production commit prompt; R15 defers_decision(to); R127 artifact audit and counterfactual minimal pairs; R133 label-shift prior correction.
NEW HARDENING: NEW context-only leakage probe. Each release, a probe is trained on (state, tool list, agent fragment) with no caller text. If it predicts the event above the class-prior baseline for that state, the release is blocked. The generator is then prompted by target event, never "customer responds", and with a balanced event mix per state. Training adds cross-state context-swap negatives and caller-text-dropout checks.

## A2
DEFENSE: Dialect transforms are Multi-VALUE-style rule transforms of labeled source items (R93), so the label is inherited, not re-judged by the teacher. The gate never trusts teacher labels. Tier A bounds come from humans listening to audio (R26). Strata are defined by observable features and annotated by two trained auditors (R131), with per-dialect bounds as release blockers (R93) and a label-free worst-cluster check. A skewed teacher therefore blocks release; it can't certify. The cited outcome is also mild: dispute_prior_statement only re-reads a table value (R91), and clarify is not a hostile exit.
EXISTING ELEMENTS: R93 dialect transforms and per-dialect release blockers; R26 human audio gold; R131 feature-based strata, two auditors, worst-cluster bound; R130 dialect allowlist exempt from quarantine; R97 extra audit where models agree confidently; R91 dispute_prior_statement re-read.
NEW HARDENING: NEW: (1) Teacher-vs-human disagreement is measured per dialect stratum each release. A disparity above threshold bars teacher labels for that stratum, which then trains only on human labels and label-inherited transforms. (2) Dialect transforms must keep the source label, enforced by a build check, and the teacher may never relabel them. (3) Matched-pair dialect tests (same content in SAE and AAE) are required to get the same event, as a Tier A stratum.

## A3
DEFENSE: Safety does not rest on synthetic coverage. Sensitive events have "deterministic lexicon pre-emption" (R19) and explicit hardship rows (R150). The red team is "model-diverse ... plus human-written seed attacks" (R97). Certification counts only real audited calls (R2), so a missed oblique ideation turn is counted Tier A harm and blocks the state. Label-free drift monitors on 100% of traffic cover out_of_scope growth and hang-up-after-turn (R132). Euphemisms are a named open item, not a hidden one.
EXISTING ELEMENTS: R19 sensitive_event plus lexicon; R150 hardship lexicon; R97 human-written attacks; R2 real-call certification; R15 vulnerability counter; R153 small_talk budget; R132 label-free drift; R119 health data quarantine; open item "euphemisms".
NEW HARDENING: NEW: (1) Each release runs a sanitization audit per Tier A sensitive and unlawful class: generator refusal rate, plus an explicitness score of the generated wording against human-written oblique sets. Failure blocks release. (2) The oblique tail comes from consented, crisis-line-informed human writers and from a non-refusing self-hosted model run in the R143 enclave. (3) Passive-ideation lexicon rows ("won't be around", "not be here anymore") route to the low-cost scripted sensitive exit. (4) sensitive_event gets an asymmetric, recall-biased threshold.

## A4
DEFENSE: No robustness number from synthetic noise certifies anything (R2). Certification runs "on live ASR text" from the pinned ASR (R26, R68), stratified by channel class (R137), so the real confusion profile is what gets measured. The canonicalizer feeds Needle canonical text in training and certification alike (R68), which removes ITN quirks like "4" for "for" before Needle sees them. The design already applies this principle elsewhere. The big model may not write prosody tokens; they come only from the pinned detector run on audio (R128).
EXISTING ELEMENTS: R2; R26 certification on live ASR text; R68 pinned ASR, canonicalizer, daily golden-audio canary; R137 channel class in certificate; R128 detector-only prosody precedent; R105 TTS-to-pinned-ASR round trip.
NEW HARDENING: NEW: LLM-written ASR errors are banned. Noisy training text is produced only by TTS (varied voices and dialects), then channel and codec simulation per certified class, then the pinned ASR and canonicalizer. A second source samples from an empirical confusion model fitted on real audited calls (human transcript vs pinned ASR output). A release check compares the synthetic and real error profiles (WER, insertion and merge rates) per channel class.

## A5
DEFENSE: A conflicted boundary can't certify. Bounds are per call, on whole audited real traces (R66), not on the new event's own test set. The goodbye boundary is a certified confusion pair, like small_talk vs unintelligible (R63). An acknowledge given to a real "okay thanks bye" counts as an error against human audio labels. Calibration re-fits event priors on a real audited split (R133). New events are added only through a threshold process (R36). "Real data never replaced" (R33) forbids swapping real data for synthetic. It does not forbid relabeling.
EXISTING ELEMENTS: R66 whole-trace per-call bounds; R63 certified confusion pairs; R26 human audio gold; R36 new-event threshold; R33; R133 calibration split; R127 artifact audit.
NEW HARDENING: NEW schema-migration step. Every schema version carries a label-map spec. A split marks every item labeled with a parent event as stale. Candidates are retrieved by lexicon and teacher; real items get human relabeling, and synthetic items are regenerated. Stale items that aren't resolved are masked from training (kept, not deleted). A build check blocks training while any parent label has unresolved stale items above a set fraction.

## A6
DEFENSE: The tool list is derived from handlers (R52), and the certificate is keyed by tool-list hash (R34, R53). Certification uses only Needle-driven real calls under the new list (R124). So "come out to my house" mapped to book_video is an audited booking error and blocks the state. Generator-prompt lineage already exists (R129), and cross-version state migration is allowed only through a model-checked map (R67). The gap is training-item provenance, which I close below.
EXISTING ELEMENTS: R52 handler-derived tool lists; R34/R53 tool-list hash in certificate; R124; R129 generator-prompt lineage; R67 model-checked migration map; R2.
NEW HARDENING: NEW: every training item stores (graph version, tool-list hash, description hash, label-map version) and only the utterance plus target event. State context is re-rendered at train time from the current graph, never from stored old descriptions. Only 1:1 renames migrate by script. A split or merge target needs human relabeling (real data) or regeneration (synthetic), else the item is masked. A build check rejects any item without a verified migration path to the current schema.

## A7
DEFENSE: The certificate never rests on reproducing training. It rests on the hashed weights' behavior on real, human-audited calls (R2, R53). Those weights are kept in immutable retained bundles (R67) with bit-identical replay. A regulator can audit the certified artifact and its evidence without rerunning the teacher. A hotfix never regenerates the old data. It adds data to the union, since real data is never replaced (R33), and recertifies on fresh samples (R126). Regression items are retained (R129) so differences show up.
EXISTING ELEMENTS: R53 weights-hash certificate; R67 immutable retained bundles; R2; R33 union of all data; R126 fresh confirmatory sample; R129 lineage and regression suite; R116 WORM retention.
NEW HARDENING: NEW: each release's exact training corpus (generated text, labels, teacher model id and version string, prompts, seeds, sampling params, run date) is content-hashed into the bundle manifest and archived in WORM. The training run is seeded and deterministic on the pinned hardware class. Later releases build on the frozen snapshot rather than regenerating it. Generation prefers a self-hosted, version-pinned open-weight teacher, so retirement can't break the archive.

## A8
DEFENSE: The gate requires humans "listening to audio" (R26). Strata use two trained auditors with measured inter-rater agreement and confusion correction (R131). Selection of "all disagreements + random agreements" (R2) uses model labels to choose clips; nothing requires showing those labels to the labeler. The commit gate is lexical (R87) and needs "send the contract" (R144). So "yeah, no, go ahead and send it" can't commit through a pre-filled affirm. Still, blind labeling must be explicit.
EXISTING ELEMENTS: R26 audio gold; R2 audit sampling; R131 two auditors, agreement and confusion correction; R143 labeling enclave; R87; R144; R97 extra audit on confident agreement.
NEW HARDENING: NEW: (1) Tier A labeling is blind. The UI shows no model or teacher label, and playback is fixed at 1x. (2) A random 10% are double-labeled blind, with adjudication and per-labeler agreement tracking. (3) Hidden known-answer items are seeded, and labelers below accuracy are removed and their labels re-done. (4) Pre-fill is allowed only for Tier B. Its bias is measured against blind double labels, and the harm estimate is corrected by that measured bias.

## A9

## A10
DEFENSE: A stop fix needs no retrain. Stop is the "union of deterministic lexicon ... and Needle GLOBAL" (final plan). "Unsubscribe me" is added as a lexicon row (as in R145 and R93), and the post-call DNC sweep catches anything missed before a redial (R66). Union can only add stops, so false-continue can only fall. GLOBAL is "versioned separately" (R34). When weights must change, equivalence-based re-keying keeps every state whose outputs are bitwise identical on its gold and canary corpus (R135). Only diverging states recertify, on fallback.
EXISTING ELEMENTS: stop = lexicon ∪ GLOBAL; R24 Tier 1 list; R66 post-call sweep; R34 separately versioned GLOBAL pass; R135 equivalence re-keying; R132 drift-triggered fallback; R115 revocation bus.
NEW HARDENING: NEW: (1) A same-day lexicon hotfix lane. The row is replayed against all retained gold sets for false-stop rate and signed off by compliance, with no weights change. (2) GLOBAL and LOCAL become separately trained weights, each with its own hash, so a safety retrain leaves LOCAL certificates intact. (3) A new event needs only the GLOBAL-pass recertification.
