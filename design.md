# Living design (Designer only, never shown to the Breaker)

## Runtime (final): Needle-only + deterministic code
- StateSmith machine: compiled enum states, deterministic transitions, guards are pure code over the slot store.
- Needle (encoder-decoder, ~26M, single-shot, emits JSON list of {name, arguments}) maps one utterance + the current state's tool schema to tool calls.
  - Needle always emits some call (no native abstain), so every state's schema includes an explicit `unclear()` tool; `unclear()` or any call not in the state's allowed set routes to the uncertainty branch.
- Independent safety detector on every utterance that pre-empts Needle: opt-out / do-not-call / stop ends the call immediately. Final runtime version = a separately trained tiny classifier (its own Needle fine-tune or small classifier), not the big model.
- Explicit tools for conditional consent, renters/non-owners, opt-outs.
- Slot store: every slot carries provenance (turn, committed vs hypothetical). quote_variant writes only to a scratch slot. confirm_order is reachable only from a read-back state bound to the exact configuration read back.
- Facts live in a versioned, owned facts table with effective dates; changing a row decertifies every branch that cites it.
- Uncertainty branch (runtime): deterministic: one scripted clarify attempt, then safe fallback (callback scheduling or human handoff). Never guesses.

## Build phase only
- Big model handles uncertain turns, generates scenarios/data, red-teams paths.
- Branch certification at ~99.99% on held-out + fresh calls; certificates expire and must be re-earned.
- Shadow sampling and drift monitoring.

## Fixes from rounds
- R1 (won): explicit unclear()/out_of_scope(topic) tools trained with off-script negatives; deterministic fallback books consult/callback; recurring questions become facts-table scripts. Open risk: unseen topic mapped to a valid in-state call.
- R2 (lost) FIX, certification redefined:
  - Gate is a per-CALL harmful-outcome bound, not per-turn accuracy. Target stated per call; per-state budgets derived from it (e.g. ~20 turns/call → per-turn budget ≈ call budget / 20).
  - Only real traffic counts toward the gate. Synthetic data trains Needle and finds bugs; it never certifies. Needle runs in shadow on live build-phase calls; its outputs are compared to the big model and a stratified human-audited gold sample (all disagreements + random agreements). Rule-of-three sample sizes are computed on those live samples per state.
  - Risk tiers: Tier A (irreversible or compliance: opt-out, confirm_order, consent, qualification-critical slots) needs a human-audited gold set; Tier B (reversible pitch moves) can use model-agreement labels with audit sampling.
  - Deterministic critical-slot read-back: any slot that gates qualification or an irreversible action (roof age, ownership, utility, config) is read back to the customer and confirmed before a transition depends on it. A single-turn Needle error becomes a caught correction, so call-level harm needs two independent errors.
  - States that cannot reach the bound on real traffic (low volume) do not go Needle-only; at final runtime they route to the deterministic fallback (callback/human handoff), never the big model.

## NEW RULE (Fahim, from round 10): speculative pre-answering
While the customer is still speaking, Needle runs on the partial transcript, guesses likely completions, and pre-computes answer + next state for each, so the reply is ready the instant they stop.
- R10 (won): speculation = cache. Speculative runs on forked staged store; never commit/speak/send. At end of turn Needle runs on full utterance; cached reply used only if canonical call set exactly equals a cached branch; else compute fresh. Barge-in: stop speaking, discard, reprocess. Tier A states use longer end-of-turn silence threshold.
- R11 (won): speculation enumerates outcomes, not words. Code enumerates each state's finite canonical call sets; Needle on prefixes only ranks; top-k outcomes get transitions pre-run and reply audio pre-rendered; exact equality with full-utterance pass selects. No completer, no fuzzy matcher.
- R12 (won): cache key = full canonical call set including every argument that changes the spoken reply.
- R13 (won): effects as data. StateSmith actions only append effect intents to an outbox in the staged store; executor drains only on committed non-speculative turns. Speculative fork = second instance of the same compiled machine (state id + slots copied) with a null sink.

## NEW SCOPE (Fahim, from round 14): whole call, open to close
Cold opening/greetings/icebreakers; nonsense or garbled utterances handled safely; a successful sale is a pass criterion.
Designer's sale definition: the close happens on the call: deterministic price from the price table → read-back of exact configuration → explicit yes → confirm_order → e-sign contract link sent (effect) and signature status tracked; site survey scheduled as the next step. Binding terms come only from deterministic pricing, never from Needle.
- R14 (won): speaking-state gating. Separate *_SPEAKING states while agent audio plays (no commit tools); AWAIT_* entered only when the question finishes playing. Short affirmations overlapping agent speech = backchannel, no event. Transcript timestamps must be checked against agent playback window so late transcripts can't land in AWAIT_CONFIRM. Confirm staged until confirmation sentence completes without barge-in.
